# Quran-reading-flow
Qur’an Reading Flow bukan Al-Qur’an baru dan bukan pengganti urutan mushaf. Ini jalur baca alternatif untuk pemula yang ingin belajar dengan lebih mudah. Ayat-ayat tetap sama, hanya disusun ulang dari konsep paling dasar hingga yang lebih kompleks. Anggap saja ini “urutan untuk bayi” sebelum menjelajah Al-Qur’an secara utuh.
